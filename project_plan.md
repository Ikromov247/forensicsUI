Objective:

1. Get user input in the image format (one or more images)
2. Get user input for videos (uploaded or provided as a path)
3. extract identifying features from the images
4. Go through the video frames and find target objects. 
5. Compare input object to target objects. Take color into consideration
6. When the object in a video matches the input object, save the subset of the video
7. Display the subset to the user.
